# Security Policy

## Supported releases

Cuff `0.1.x` receives security fixes. Reproduce a report against the newest
published `0.1.x` release when practical.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/fab7hq/cuff/security/advisories/new).
Include the affected version, platform, reproduction steps, impact, and any
suggested mitigation. Remove credentials, private source, and unrelated logs.

Do not open a public issue for an unpatched vulnerability. If private reporting
is unavailable, open a public issue that asks the maintainer for a private
contact channel without disclosing the vulnerability.

Cuff records integrity and provenance evidence; it does not guarantee semantic
correctness, security, compliance, or resistance to a malicious local actor.
